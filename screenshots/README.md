# Demo assets

This folder contains a source-derived visual reference and the capture notes
for a future SignToROSS product demo.

## Workflow board

- `signtoross-workflow.svg` is the editable source.
- `signtoross-workflow.png` is a rendered image for the GitHub README.
- The board follows the implemented Mike -> OpenSign -> callback -> signed PDF
  path. It is a product-demo visual, not a claim that a live signing envelope
  was created.

## Live reference

- `test-autoyou-cloud-plans.png` is a public capture of
  `https://test.autoyou.me/`, retained as a companion AutoYou entry reference.
- `test-autoyou-plans-detail.png` and `test-autoyou-plans-dark.png` show the
  lower plan section and its alternate theme.
- The live page currently shows plan selection, not an authenticated
  SignToROSS workspace.

## Live native AutoYou companion

- `autoyou-mobile-demo-live-native.mp4` is the 45-second uncaptioned master
  from the real AutoYou Android app on a disposable emulator. It shows an
  active connection, a typed request, a live reply, and a return to the
  connection view.
- `autoyou-mobile-demo-live-vertical.mp4` is the 36-second portrait social
  cut with inlaid captions. It is continuous footage with no slide cards,
  zoom pans, crossfades, or screenshot sequence.
- `autoyou-mobile-demo-live-poster.png` is the captioned poster frame.
- `mobile-demo-live-capture.md` documents the safe capture conditions.
- `mobile-demo-live-captions.ass` is the editable caption track.

This is an AutoYou companion reference. It does not show a completed SignToROSS
envelope or signature. The reply was exercised against a disposable local
AutoYou Lite fixture with synthetic provider text.

## Screenshot-based portrait reference

- `autoyou-mobile-demo-vertical.mp4` is a 23-second 1080 x 1920 walkthrough
  built from real AutoYou mobile UI captures. It is preserved as an earlier
  visual treatment reference and is not the primary live demo.
- `autoyou-mobile-demo-vertical-poster.png` is the portrait README poster.
- `mobile-demo-script.md` records the sequence and caption copy.

## Video reference

- `test-autoyou-reference.mp4` is a short browser-state reel made only from
  the public `test.autoyou.me` entry screen.
- `test-autoyou-vertical-reference.mp4` is the portrait version of the live
  public-site reference, with the same signed-out caveat.
- `signtoross-demo-reference.mp4` is a short static reel using the live
  AutoYou reference and the source-derived SignToROSS workflow board.
- `demo-script.md` describes the safe future capture with synthetic documents
  and recipients.
